Sobre mí

Soy desarrollador full-stack. Trabajo tanto en sitios de cara al público — landings, sitios institucionales — como en sistemas internos que un negocio usa a diario: control de stock, rutas de entrega, gestión de clientes.

Me interesa particularmente conectar el frontend con datos reales: catálogos que se actualizan solos, paneles que reflejan el estado actual de una operación, no capturas estáticas. Uso React cuando el proyecto lo pide y JavaScript vanilla cuando no hace falta más.

Gran parte de este trabajo lo hice con asistencia de IA como parte de mi flujo: la uso para acelerar la implementación, pero las decisiones de arquitectura, qué construir y cómo resolver cada caso de uso son mías.
